# DBMS_risk_management_project
Here's a brief description of the project:

ERM-DB is a centralized database system that replaces scattered spreadsheets for tracking business risks. It allows teams to log risks (e.g., vendor outages, compliance gaps), automatically calculates severity scores, sends alerts when risks go unmanaged, and maintains a full audit trail. The system enables fast reporting for audits and links risks directly to risk owners and control measures—all in one place.
